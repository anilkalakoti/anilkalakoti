## 🔬 Featured Projects

### ⚡ Distributed Event Processing Gateway
A resilient, idempotent microservice built on ASP.NET Core and Entity Framework Core designed to process high-throughput transaction streams with distributed tracing and custom fault tolerance policies.

* **Highlights:**
  * Configured resilience pipelines (retry with exponential backoff, circuit breaker, and bulkhead isolation) using Polly.
  * Computed balances dynamically on read using immutable event streams to guarantee correct ordering.
  * Implemented OpenTelemetry OTLP tracing and metrics exportable to Grafana and Jaeger dashboards.

`.NET` | `C#` | `ASP.NET Core` | `EF Core` | `OpenTelemetry` | `Docker`

### 🔍 Insurance Agent Portal — RAG & Hybrid Search Engine
An agent portal backed by Node.js, Express, and Prisma ORM using ParadeDB running in Docker containers. Integrated with OpenAI API endpoints to handle dynamic user inquiries while scoping permissions based on user roles.

* **Highlights:**
  * **Hybrid Search Retrieval:** Combines sparse BM25 indexing with dense pgvector HNSW indexing inside a single PostgreSQL container.
  * **LangChain Orchestration:** Dynamic context building with strict safety guardrails to ensure role-based data isolation.
  * **Containerized Development:** Optimized build configurations for Alpine Linux environments using Docker Desktop.

`Node.js` | `Express` | `Prisma` | `ParadeDB` |
